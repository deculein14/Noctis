# Noctis
A private, local-first personal information manager designed to securely organize and protect the information that matters to you.

Noctis is a desktop application focused on giving users a private and organized place to manage their personal information.

It started as a password manager, but its goal has expanded beyond passwords. Noctis is being developed as a broader personal information management application where different types of sensitive and important information can be stored, organized, and managed in one place.
